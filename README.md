# OS Manager

Aplicativo Flutter para gerenciamento de ordens de serviço e manutenção técnica, com persistência local em SQLite.

## Recursos

- Login visual com matrícula e senha.
- Dashboard com indicadores de ordens e valores estimados.
- Cadastro, edição, visualização e exclusão de clientes e técnicos.
- Cadastro, edição, visualização e exclusão de ordens de serviço.
- Prioridades, status, datas, diagnóstico, solução, valores e anexo de imagem na OS.
- Navegação inferior para Início, Clientes, Técnicos e Ordens.

## Execução

Com o Flutter instalado, execute:

```bash
flutter pub get
flutter run
```

No Windows, habilite o Modo de Desenvolvedor caso o Flutter solicite suporte a links simbólicos para os plugins.
